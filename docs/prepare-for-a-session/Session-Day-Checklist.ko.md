# 시험 당일 빠른 참조 체크리스트

_San Diego County Amateur Radio Council | The Coolest VEC | vec@sandarc.org_

---

## 응시자 도착 전

- [ ] 참석한 모든 VE가 SANDARC 인증을 받았는지 확인(확실하지 않으면 팀 리드에게 문의)
- [ ] 응시자와 친족 관계인 VE가 있는지 확인하고, 해당 시험은 친족 관계가 없는 VE 세 명이 인증하도록 조치([정책](../conduct-a-session/Conducting-the-Session.md#family-members-and-observers))
- [ ] [ExamTools](https://exam.tools)에 세션이 생성되어 접속 가능한지 확인
- [ ] 연습용 종이, 연필, 계산기 - 준비 가능한 경우(메모리는 초기화)
- [ ] 시험 구역이 조용하고 방해 요소가 없는지 확인([참관인은 허용됨](../conduct-a-session/Conducting-the-Session.md#family-members-and-observers))
- [ ] **녹음·녹화 장비 작동 금지:** SANDARC 세션에서는 모든 녹음·녹화가 금지됩니다(홍보용 사진만 예외이며, 신분증, 서류, 시험 화면은 절대 촬영 금지)
- [ ] 세션 장소에 다른 VEC의 브랜드 표시가 보이지 않도록 확인

## 응시자 접수

- [ ] Greet each applicant warmly
- [ ] 사진이 있는 신분증 확인: 신분증의 번호는 어떤 것도 적어두지 말고, 신분증을 사진이나 영상으로 촬영하지 마십시오([자세한 내용](../conduct-a-session/Conducting-the-Session.md#applicant-check-in))
- [ ] 사진이 있는 신분증이 없는 미성년자의 경우: 부모 또는 보호자가 신원을 확인해 줄 수 있습니다
- [ ] 13세 미만 응시자의 경우: 부모 또는 보호자가 등록했는지, COPPA 동의가 접수되어 있는지 확인([COPPA 절차](COPPA-and-Minors.md))
- [ ] 엘리먼트 크레딧 관련 서류 검토: 사본을 만들고 원본은 반환([크레딧 표](../conduct-a-session/Conducting-the-Session.md#element-credit))
- [ ] [ExamTools](https://exam.tools) 명단에 응시자 추가
- [ ] Remind applicant: SANDARC charges no exam fee, but the FCC charges a separate $35 fee after submission of any new license!

## 시험 진행 중

- [ ] 시험 시작 전에 모든 응시자에게 세션 규정 안내([안내 사항](../conduct-a-session/Conducting-the-Session.md#session-announcements))
- [ ] [ExamTools](https://exam.tools)를 통해 시험 배포(태블릿, 컴퓨터 또는 인쇄물)
- [ ] 항상 최소 3명의 VE가 모든 응시자를 감독하고, 팀이 3명 미만으로 줄어들면 모든 시험을 중단
- [ ] VE는 독서를 하거나 불필요한 대화를 하지 않도록 함
- [ ] **화면 캡처를 포함한 모든 형태의 녹음·녹화 금지**, 홍보용 사진만 허용되며 신분증, 서류, 시험 화면이 보이지 않아야 함
- [ ] 각 엘리먼트는 완료 직후 채점하고, 응시자에게 점수 통보
- [ ] 합격한 경우: 응시자가 원하면 다음 엘리먼트에 응시할 수 있도록 허용하거나 팀 정책에 따라 처리([재응시](../conduct-a-session/Conducting-the-Session.md#retesting))
- [ ] 응시자와 함께 CSCE에 서명하고 모든 정보가 정확한지 확인([CSCE 개요](../conduct-a-session/CSCE-Overview.md))
- [ ] 등급을 상향한 응시자에게 임시 식별 부호(/AG, /AE) 안내
- [ ] 신규 면허자에게 FCC ULS에 면허가 등록될 때까지 송신할 수 없음을 안내

## 마지막 응시자가 퇴장한 후

- [ ] [ExamTools](https://exam.tools)에서 세션 마감 후 VEC Archive 파일 다운로드(다운로드한 아카이브는 절대 열지 마십시오)
- [ ] VEC Archive 파일과 증빙 서류를 **24시간** 이내에 vec@sandarc.org로 이메일 전송([제출 절차](../post-session-information/After-the-Session.md))
- [ ] Retain your copy of all session records until SANDARC confirms processing
- [ ] 잘된 점과 다음에 개선할 점을 팀에 공유
